# Outlook integration — dry-run only
Use a trusted server and authorized Microsoft Graph Mail.Send permission only after legal and security approval. Keep credentials outside GitHub and browser code. Resolve the exact recipient from private storage, validate evidence and purpose, check suppression and withdrawal immediately before dispatch, serialize revocations and send authorization, and use an idempotent outbox with controlled retries. Never send on missing or unavailable consent data. Include sender identity and effective unsubscribe mechanism. Audit minimal dispatch metadata; apply approved retention. Test synthetic records and mock transport first. No real send adapter, OAuth credentials, hosting or live database configured. Existing manual and automated sends are outside this prototype and must remain subject to separate controls.
