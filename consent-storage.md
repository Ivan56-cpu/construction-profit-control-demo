# Consent registry — prototype
SQLite is a candidate for a single trusted server, not GitHub Pages. No production host selected. Never commit database files, exports, tokens or real contact data. Use authenticated server-side access, encrypted storage and backups, least privilege, parameterized queries and verified confirmation tokens. Record exact consent wording and notice versions in an immutable version catalog. Revocation must atomically suppress sending; reactivation requires a new verified consent. Resolve event ordering deterministically and recheck eligibility immediately before each send. Establish approved retention and deletion rules, including minimal suppression evidence, and test restoration and rights requests. Use synthetic records only until legal and security review. The SQL schema is a starting point, not a running service or a complete implementation.
